# Word 局部精修

局部任务以用户的最新 DOCX 为底稿，保留未涉及区域。格式依据见 [版式规范](style-spec.md)，验收见 [验收规则](acceptance.md)；完整新建优先使用 [原生组件](construction.md)。

## 确定编辑目标

读取本轮文件，不直接重跑旧生成脚本。用户可能已改过位置、字体、分组、链接或页数；用原文字、对象名称、相邻标题和坐标共同定位目标，不能依赖固定的“第几个文本框”。目标不唯一时继续检查。

恢复内容先核对用户指定文字来源，再在最新文件中插入。仅为腾出必要空间移动邻近对象，不把整页恢复为早期版本。记录需要保持的文本、格式、位置和关系以供前后比较。

## 选择操作粒度

仅补图标、恢复一行或改指定段落时，可直接编辑对应 OOXML 并保持其他 ZIP 部件不变。高层库重新保存复杂分组文档可能引入范围外变化，使用能保留对象结构的路径。

- 每个逻辑段落单独成框，复制时保留完整 runs、链接、公式及强调。整体转换时再统一字体，避免旧直接格式覆盖规范。
- 栏目复制完整的标题与横线原生组；机构复制完整的底色、独立图标和透明文字框原生组。不能只抽取首个形状。
- 新对象设置明确角色名称、唯一 ID、锚点和尺寸。组内坐标、缩放与页面坐标分别换算，更新几何时同时检查组的范围与子对象范围。
- 分离机构图片与文字后重新安排图片区域、字段起点和制表位；图标不再参与段落行高。透明文字框居中后检查实际字形位置。
- 行首出现逗号等异常标点时，先核对实际 run 的东亚语言、段落中文禁则、标点溢出和兼容设置，再核对自然换行；保留正确的原生悬挂缩进。不能仅插入回车或空格遮掩问题，也不能以另一渲染器正常代替用户实际显示的验证。
- 不为处理方便接受全部修订、删批注或把公式变成图片。修订视图影响内容依据时先确定核对视图。

## 关系与兼容表示

`rId` 只在所属部件有效，复制图片或超链接时保留或重建对应关系及目标。对象标识在有效表示中保持唯一，不能连同旧对象身份直接复制。

`mc:AlternateContent` 可能同时存储 DrawingML 与 VML 表示。清点只选一个有效分支，修改时同步已有兼容分支，避免旧环境显示过时内容。只有确认缓存因本次修改失效时，才按已验证方式移除或重建缓存，不清空未知部件。

未涉及的 XML 与 ZIP 部件尽量原样保留。包可读取、关系有效不代表页面正确，保存后仍需渲染。

## 图标与链接

按 [图标流程](icons.md) 获取并核验资源。机构图标独立于文字，联系方式和项目仓库的小图标可以与文字同行；按有效图形而非透明画布确定视觉大小。

替换图片时同时检查关系、名称及替代文本。保留真实个人或项目目标，不能把图标来源页面当成简历链接，也不能继承其他平台的目标。

项目仓库使用同一项目小标题框中的右对齐制表位；联系方式遵循用户的单行或多行选择。调整显示标签及照片位置时保留真实链接，不用连续空格或无效标签凑版。

完成后返回验收流程，对照实际文字、对象、关系和同环境前后渲染，确认修改范围及必要的邻近调整。
