# 定稿版式规范

整体优化、新生成或统一简历格式时，本文件是默认视觉规范。先看两页参照，再排版；不得只读取原稿文字后自由选择另一套设计。样例规定布局、字体和颜色用途，实际主题色从当前选定经历图标取得；用户指定的新风格、纸型或保留范围优先。

## 参考材料

- [脱敏 Word 样例](../assets/layout-reference.docx)：从空白文档按版式参数重建，含可编辑文本框、条带和原生占位图形，可读取或复制其样式；不能覆盖此文件。
- [第 1 页参照](../assets/layout-page-1.png)：姓名、联系方式、头像、教育背景与实习项目的视觉关系。
- [第 2 页参照](../assets/layout-page-2.png)：科研项目、论文引用和作者强调的视觉关系。

样例只保留已确认的视觉参数，未复用用户原件中的文字、图片或二进制部件。所有人物、机构、经历、论文及日期均为虚构占位内容，所有链接使用 example.com 保留域名，照片为灰色占位框。机构和联系图标使用不指向真实个人或机构的示意符号；正式简历应替换为当前用户的真实材料和相应机构图标。

脱敏样例 SHA-256：`814d57eb19a00352b5241119b99ab928528dad04bed8f07313726871a74503d1`。

## 必须保持的视觉特征

1. 单栏、紧凑的技术科研简历；左上姓名，右上证件照槽位，正文按纵向内容块展开。
2. 栏目标题使用可读的主题色、加粗楷体和下划线；正文保持黑灰色，不把所有层级改成同色同字号。
3. 学校、公司抬头使用横贯正文宽度的主题浅色底条带，图标置左，机构名及专业或团队信息在左/中，学位、项目计划等在中后列对齐，日期靠右。
4. 项目名采用同主题的深色变体加粗；背景、职责和技术分项采用圆点层级与加粗标签，正文清楚解释技术工作。
5. 论文标题行使用英文衬线字体、斜体和适当加粗；突出当前简历作者的姓名，保留真实的共同一作等标记。其他论文形成紧凑列表。
6. 标题、机构条带、项目内容与论文引用保留为原生可编辑对象，主要内容使用可移动文本框；不能用整页截图交付。

## 图标派生配色

### 选一个经历作为全篇主题来源

- 用户指定某段经历或机构时，以该图标为准；用户直接指定色值时优先使用其选择。
- 未指定时，从当前简历中选最新且有可用彩色图标的工作经历；并列时取页面顺序第一项。没有工作经历彩图标时，选当前或最近教育经历的彩图标。
- 只选一个主题来源，统一教育、实习、科研和论文栏目。其他图标保留原色；不默认给每段经历另配一套颜色。
- 不从个人照片、电话、邮箱、GitHub 或 Scholar 联系方式图标选择简历主题。没有合适的经历彩图标时，沿用用户已有主题；仍无主题则用中性深灰和浅灰，不回退到固定红色。
- 局部补文字、加图标不触发全篇重新取色；只有整体优化或用户要求换配色时才执行。

### 取色与映射

查看图标的有效图形区域，忽略透明区域、白底、边缘抗锯齿与黑色辅助文字。多色标识选一个最有代表性的主色；保留图标本身，不给品牌图标染色。无需为了取色把用户原图保存进可复用 skill。

| 颜色用途 | 派生方法 |
| --- | --- |
| 图标主色 | 选定经历图标中有代表性的有彩色部分。 |
| 可读主题色 | 用于栏目、下划线、作者强调；主色过浅或过亮时，保持色相并加深到白底上清楚可读。 |
| 主题深色 | 用于机构名称、计划、日期及项目标题；从同一主色加深，与正文黑灰形成层级。 |
| 条带浅底 | 默认将主色以 10% 混入白色；RGB 每通道计算为 `round(0.1 × 主色通道 + 0.9 × 255)`。也可使用 10% 不透明度，OOXML alpha=10000；白底渲染后再核对。 |
| 正文与链接 | 正文保持 `#262626`；超链接保留可识别的链接样式，不把所有正文染成主题色。 |

橙、黄、荧光绿等亮色不直接用作小字号文字；文字用同色系深色，背景保留浅色。检查实际渲染中的文字和条带是否清晰，避免浅字浅底或大面积高饱和底色。

### 脱敏样例只演示规则

当前样例以虚构“示例科技公司甲”的蓝色图标为取色源：主色 `#2F6FBA`，文字深色 `#265995`，10% 浅底约 `#EAF1F8`。其他虚构图标有不同颜色，但全篇栏目和条带仍采用这一套主题。此蓝色不是默认品牌色；生成真实简历时，按当前用户选定经历重新取色，保留示例的颜色用途及深浅关系。

## 页面、字体和颜色

下列值是已提炼的版式参数。脱敏样例显式应用这些参数，避免依赖其他文档的 Normal 样式而改变外观；其内容长度和局部间距用于展示，可按真实材料调整。

| 项目 | 默认参数与用法 |
| --- | --- |
| 页面 | 竖向，595.3 × 864.55 pt，约 210 × 305 mm；这是参考的自定义纸型，不称为标准 A4。用户指定 A4 时改为 A4 并重新排版。 |
| 节页边距 | 左右 34 pt，上下 28.35 pt；浮动对象另有页面坐标，不能只用节边距推断实际左边界。 |
| 主要内容宽度 | 527.3 pt；沿参考的实际内容左线对齐，按当前页宽与安全边界调整。 |
| 中文字体 | 主要使用 KaiTi（楷体）。检查字体是否可用；如需兼容字体，使用接近的楷体并重新验证行数和分页。 |
| 英文、数字 | Times New Roman；不要把英文技术名称统一改成无衬线字体。 |
| 姓名 | 20 pt，黑灰色，加粗，左对齐。 |
| 栏目标题 | 14 pt，可读主题色，加粗、下划线；下划线随标题，不延伸成横贯整页的大分隔线。 |
| 机构抬头 | 11 pt，加粗，主题深色变体；保持同一条带内各字段的基线一致。 |
| 项目标题 | 10.5 pt，加粗，主题深色变体；全篇同级项目保持一致。 |
| 正文 | 主要为 10.5 pt，中文楷体、英文 Times New Roman，颜色 `#262626`；标签加粗，职责句可整体加粗，技术说明正文保持常规字重。 |
| 联系信息 | 主要 11 pt；链接保持可点击及蓝色下划线，附属统计说明可以用 10 pt。 |
| 论文题录 | 10.5 pt，Times New Roman，主要科研项目题录加粗、斜体；其他论文题录斜体、序号普通。当前作者名以可读主题色强调。 |
| 机构条带底色 | 选定图标主色与白色混合；默认 10% 主色、90% 白色，可在 8–12% 主色间微调。无粗边框。 |
| 机构条带尺寸 | 527.3 × 21.1 pt，文字左缩进 24 pt 为图标留空；长字段需要增高时保持字号和列关系。 |
| 文本框内边距 | 通常左右 0、上下 2 pt，顶部对齐；框的存储高度不能替代渲染后的文字高度。 |

不要把空白宿主段落的 1 pt 行距或其他不可见属性误当正文规范。读取任意源文档时，字号可能来自样式继承，不能只统计 `w:sz`。

## 行距、层级与对齐

- 正文常用 1.2 倍行距（`w:line=288`、`lineRule=auto`）；不是固定 14.4 pt。采用同样字体字号后通过渲染确认实际行高。
- 正文通常两端对齐，姓名和联系方式左对齐；段前段后以 0 为起点，内容块间空白通过框的位置和高度控制。不要用断字或连续空格制造两端对齐。
- 联系方式采用约 18 pt 固定行高，使图标和文字基线稳定；机构条带的文字垂直居中。
- 一级说明使用实心圆点；技术分项使用空心圆点、适度缩进，并将“训练管线搭建”“算法探索”“项目产出”等标签加粗。续行对齐正文起点，不回到圆点位置。
- 一级圆点正文左缩进 7.1 pt、悬挂 7.1 pt；二级默认可取左缩进 12.75 pt、悬挂 7.1 pt，参考另有左缩进 17 pt 的较深版本。新稿同级条目选定一种并统一，保持实心/空心两级差异。
- 引用列表保留清楚的编号、作者、题名和出版信息；作者强调只作用于当前候选人，不能沿用标本中的姓名。
- 保持统一左线和日期右线。教育条带可按“图标/学校—专业—学位—日期”，实习条带可按“图标/公司团队—计划或岗位—日期”。字段宽度按真实文字调整，不靠连续空格凑列。
- 参考的教育条制表位为左对齐 126 pt、左对齐 357 pt、右对齐 527.3 pt；实习条为左对齐 126 pt、左对齐 273 pt、右对齐 527.3 pt，均相对条带文字区域。可以复用为起点；长机构名会越过前一个制表位，必须检查实际落列。
- 文本框的高度、段间空白和后续对象纵坐标由内容决定。先确定可读行高与段落高度，再放置下一个项目；不要逐框填入新文案后保持旧高度不动。
- 标题与至少一段正文同页。内容装不下时调整分项组织、段间距或分页；不得为保持两页而裁切、遮挡或删除事实，也不先把正文字号缩小。

## 页首与图标

姓名在左上，照片槽位在右上，二者留出清楚的间隔。脱敏样例中仅有原生灰色占位框。用户未提供照片时留出合理空白或收回槽位。

以最终版的联系方式层级为默认：

1. 电话、邮箱和即时通讯信息在第一行，图标在前，使用 `｜` 分隔；仅保留用户实际提供的字段。
2. Google Scholar 单独一行，可附当前用户提供或确认的引用统计。
3. GitHub 单独一行，图标后接名称或有效 URL。

这取代历史中间稿“所有字段强塞一行”的默认。如果用户当前明确要求所有联系方式同一行，再按可用宽度调整标签和头像位置。

联系图标以 11 pt 左右的视觉高度为起点，保持纵横比；Scholar 为 11 × 11 pt，GitHub 为约 11.23 × 11 pt，图片 run 下移 1 pt 与文字协调。学校/公司图标一般 18 × 18 pt，横向机构图标可取 20 × 17 pt；品牌外形不同时保持比例并按视觉高度协调。图标右侧留出文字间隙。不能使用 emoji 回退效果代替需要稳定显示的品牌图标。

脱敏样例姓名框位于页面 `(34, 27.45)` pt，三行联系信息顶部依次为 58、80、102 pt，左线统一为 34 pt；姓名及联系框宽度可根据文字长度调整。照片占位框约 76.17 × 106.64 pt，位于右上。坐标用于展示布局关系，实际内容变化时重新计算高度与间距。

若使用抬头区细线，沿用主题色，并与联系方式、头像分开，不穿过文字。超链接可保持蓝色下划线以便识别；装饰元素不另引入一套配色。

## 实现与验收

- 只从**已脱敏样例**复制样式、文本框或条带结构，再替换为当前内容；也可以在最新文档中应用参数。不得将用户原件或截图打包进 skill，也不得通过旧生成脚本覆盖当前用户修改。
- 机构条带包含背景、图标、文字的分组结构。修改现有条带时尽量保持分组，避免拆散后各部分错位；新条带使用同样可编辑的结构。
- 项目正文可按逻辑段落成框；相关标题与正文保持可辨认的层级。联系方式、日期与图标关系需在改变宽度后重新验证。
- 导入任何材料时，检查 `INCLUDEPICTURE`、缓存大图、隐藏对象和缩略图等内容。脱敏不能只替换可见文字；不得把这些未检查的部件复制进样例。
- 先按选定图标替换所有主题字体、条带、下划线及装饰线，再保持同类元素的字号、边界与基线一致，再根据内容调高度。核对标题、条带、字体、缩进、日期和图片六类视觉参数，不能把“文字内容没丢”当作版式合格。
- 渲染所有页面并与参照并排观察。目标是复现层级、颜色用途及深浅关系、密度和对齐；实际色值随当前选定图标改变，不以与样例颜色相同作为验收条件。

**生成时重新验收：** 样例中的占位文字不决定实际简历的行数与段落高度。内容替换后，重新计算文本框高度、留白和分页，检查重叠、裁切与页尾溢出。样例中的虚构内容和演示空白不能作为最终履历直接交付。
