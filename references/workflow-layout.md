# 排版与格式流程

本文件负责从已整理的内容到可编辑 DOCX；数值、颜色用途和对象粒度取自 [版式规范](style-spec.md)，完成条件统一见 [验收](acceptance.md)。用户指定的风格和保留范围优先。

## 1. 读取底稿与准备工具

- **整体新建**：读取完整 skill 包、版式规范及其两页脱敏参照，取得内容撰写流程输出的内容单元。样例的页数、占位文字和留白不决定新简历的篇幅。
- **整体优化已有文件**：读取最新版并清点正文、表格、文本框、分组、图片、链接、公式、页眉页脚和修订。复用达标对象，对不符合目标格式的区域应用组件结构；保留原有内容与用户保护区域。
- **局部编辑**：定位唯一目标，记录当前样式与邻近布局，按 [Word 精修](word-editing.md) 修补。不能通过旧生成脚本重建整份文件来覆盖手工调整。

用 `scripts/docx_inventory.py` 记录 DOCX 内容与对象基线；其读法和局限在 [清点工具](acceptance.md#清点工具与证据)。有现存底稿时在可用的同一字体环境渲染，记录编辑位置与原有问题。不要仅使用高层库的 `Document.paragraphs` 读取浮动文本框文档。

通过环境的依赖发现能力确认 Python、DOCX 编辑、目标字体和渲染工具；若提供 documents 技能，按其工具和渲染要求执行。包不完整时先取得缺失资源；取得不了仍可整理文案，但不能宣称复现模板。没有目标字体或无法渲染时记录限制，继续可做部分，交给验收决定交付状态。

## 2. 准备图标与主题

按 [图标获取](icons.md) 列出真实学校、任职机构和已有联系平台，复用已核实资源或从官方来源搜索下载，检查图形后放入任务工作目录。个人项目、开源贡献和任职关系分别处理，不从项目名称推导任职机构。

完整排版在取得经历图标后按 [配色规则](style-spec.md#图标派生配色) 选择一个主题来源，记录来源和派生色。局部补图标沿用当前主题，不触发全篇换色。不能把“用户没有上传图标”直接当作不可取得图标。

只为实际提供的信息安排页首：没有主页地址则省略该项，没有照片默认收回槽位；用户明确要求可填写模板或预留照片时例外。既有照片、公式和有效链接与对应内容共同保留。

## 3. 应用组件与对象结构

整体任务按 [内容单元与对象结构](style-spec.md#内容单元与对象结构) 建立“内容单元 → 框/条带”的对应关系。一个自然换行的逻辑段落仍是一个框，不能按视觉行拆分；也不能用多个段落或手动换行把不同分项塞进一个框。

新建完整文档调用 [构建模块](construction.md)。模块复用脱敏样例的对象、字体与原生编号，调用者传入实际文字、链接和图片。姓名、栏目、项目标题、正文、分项和论文分别成框；机构条带内的图标、背景及各字段共同移动。不要把样例占位符、虚构身份或示例外链带入成稿。

整体优化已有文件时，按同样的结构和字体映射处理需转换的区域，保留段内粗斜体、链接、原生公式、编号及批注修订状态。具体 OOXML 定位、兼容分支和关系处理见 [Word 精修](word-editing.md)。工具缺少某种对象的保真支持时先选可保真的编辑方式，不通过删除对象绕过问题。

字体与字号按元素及中西文显式写入，包括超链接和编号；仅改 Normal 样式或 `font.name` 不足以完成映射。图标嵌入本文件关系，正文中的主页、电话和邮箱使用真实目标，不沿用复制来源的链接。

## 4. 按文字调整布局

根据实际内容估算框高：考虑目标字号、行距、内边距与自然换行，再设置下一块纵坐标。构建模块默认高度只是起点，不会自动测高或分页。字段过长时调整机构列宽/制表位或增加条带高度，不让日期与前一列重叠。

先安排姓名、实际联系行及用户提供的照片，再排列栏目和经历。联系方式通常按规范分行；用户要求全部一行时使用其指定分隔符，通过字段标签、可用宽度和头像位置调整，保留每项图标与有效链接。

标题与至少一段正文同页。内容放不下时依次调整框高、合理间距和分页；需要压缩重复表述时返回 [内容流程](workflow-content.md)，保留事实对应关系。不要固定样例页数或缩小正文来掩盖容量问题，跨页段落不能塞进单个固定高度形状。

## 5. 渲染并移交验收

保存新版本并渲染所有页面；局部编辑使用同一环境生成前后结果。移交实际 DOCX、各页渲染、内容对应与对象记录、图标清单，以及明确的未解决项。任务内工作笔记即可承载记录，不必为每次小改额外交付报告。

接下来执行 [验收](acceptance.md)。渲染出图片不等于通过；裁切、溢出或错位返回本流程，事实问题返回内容流程。返修只改问题相关范围，并更新受影响页面的渲染。
