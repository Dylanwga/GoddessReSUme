# 版式规范

本文件是 GoddessReSUme 默认版式的唯一参数依据，供 [排版流程](workflow-layout.md) 和 [验收](acceptance.md) 共同引用。用户本轮指定的风格、纸型和保护区域优先；将差异记录为本轮选择，不改写全局默认值。具体操作分别见流程、图标及构建参考。

- [脱敏 Word 样例](../assets/layout-reference.docx)：可读取或复制其样式和原生对象，不能覆盖此文件。
- [第 1 页参照](../assets/layout-page-1-21474b52.png)：页首、联系方式、头像、教育与实习项目。
- [第 2 页参照](../assets/layout-page-2-9f46c32e.png)：科研项目、论文题录与作者强调。

样例从空白文档重建；人物、机构、经历、论文和日期均为虚构，链接使用 example.com 保留域名，照片为原生灰色占位框。机构及联系图标仅示意结构。样例规定字体、层级、颜色用途和对象关系，不提供候选人事实，也不要求新简历照搬框数、页数和留白。

样例 SHA-256：`846748f1d2573740a0094e5ace624e2176b521b335e0140b6501b0f716cee0a1`。

维护参考时只提炼字体、配色、尺寸、间距、对齐和对象结构。新增样例从空白文档构建，使用明确虚构的全部资料与原生照片占位框；预览由该样例重新渲染。用户原件、原件截图、渲染 PDF 或嵌入部件不得放入 skill。检查 XML、关系、超链接、作者元数据、批注修订、隐藏内容、缓存、媒体及缩略图；清理本次构建专用的未脱敏副本，用户原始文件与正式输出不在清理范围。

## 内容单元与对象结构

默认单栏、紧凑布局：姓名在左上，用户提供的照片在右上；图标联系方式位于姓名下方；正文按栏目、机构和项目纵向展开。栏目为主题色加粗文字及全宽粗横线，机构为浅色条带，项目标题为同系深色，正文为黑灰色。

| 内容单元 | 原生对象要求 |
| --- | --- |
| 姓名、栏目标题、项目标题 | 每项一个独立文本框；栏目标题与粗横线共同移动。 |
| 联系方式 | 每个设计行一个框；该行图标、超链接与分隔符同框。 |
| 学校/公司抬头 | 每条一个抬头框，字段用真实制表位排列；背景与图标可在同一框内，或与抬头原生分组。整条可共同移动，不把背景与三列字段拆成无关联对象。 |
| 背景、职责、技术实现、成果 | 每个非空逻辑段落一个框；每条一级/二级项目符号单独成框，标签留在该段内。 |
| 论文题录 | 每篇一个框；同篇作者、标题、出版信息和链接可共同自然换行。 |

“项目标题 + 背景 + 职责 + 两条技术分项 + 结果”对应六个独立框。自然换行不拆框；用多个段落或手动换行把不同条目塞在同一框内不合格。不能用整页/整段经历大框、表格单元格或截图替代；只对同一机构条带作必要分组，不把各项目段落锁进整页大组。

## 图标派生配色

先按 [图标获取](icons.md) 准备经历图标，再应用以下优先级：

1. 用户指定主题色时直接采用；指定经历时以该经历图标为来源。
2. 未指定时，选最新且有可用彩图标的工作经历；并列取页面顺序第一项。没有时选当前或最近教育经历的彩图标。
3. 无合适经历彩图标时沿用用户已有主题；仍无主题则用中性深灰和浅灰。输入没有附图不等于图标不可取得。

全篇只选一个来源，其他图标保持原色，不逐经历换主题。不得从个人照片或电话、邮箱、GitHub、Scholar 等联系图标选主题。局部修改不触发全篇重新取色。

取有效图形区域的代表性主色，忽略透明、白底、边缘抗锯齿和黑色辅助字。多色标识选最具代表性的色相，保持品牌图形原色与比例。

| 用途 | 颜色关系 |
| --- | --- |
| 栏目文字、粗横线、作者强调 | 可读主题色；主色过浅或过亮时保持色相并加深，以白底清楚可读为准。 |
| 机构字段、项目标题 | 同一主色的深色变体，形成文字层级。 |
| 机构浅底 | 默认主色 10% 与白色 90% 混合：各 RGB 通道 `round(0.1 × 主色通道 + 0.9 × 255)`；可在 8–12% 主色间微调。采用透明度时 OOXML alpha=10000 对应 10%。 |
| 正文、链接 | 正文 `#262626`；链接蓝色下划线并有真实目标，不将整篇正文染为主题色。 |

橙、黄、荧光绿等高亮主色不直接用作小字号文字。脱敏样例演示蓝色主色 `#2F6FBA`、深色 `#265995`、浅底约 `#EAF1F8`；这不是真实简历的固定默认配色。

## 页面与文字参数

| 项目 | 默认参数 |
| --- | --- |
| 页面 | 竖向 595.3 × 864.55 pt，约 210 × 305 mm，自定义纸型；不是标准 A4。用户指定 A4 时调整纸型并重新分页。 |
| 节边距 | 左右 34 pt，上下 28.35 pt。浮动对象另有页面坐标，不能仅凭节边距推断实际边界。 |
| 页底安全边界 | 浮动正文框的底部不得进入本表规定的下页边距，实际文字也须完整落在该边界内；仅未越过纸边不算满足安全边界。 |
| 内容列 | 左线通常为页面 x=34 pt，宽 527.3 pt；按当前页宽和安全边界调整。 |
| 中文 | KaiTi（楷体），包括中文标点；覆盖姓名、标题、机构、正文及中文联系方式。 |
| 西文与数字 | Times New Roman，包括技术词、日期、论文及普通链接。 |
| 姓名 | 20 pt，黑灰、加粗、左对齐。 |
| 栏目标题 | 14 pt、可读主题色、加粗；文字不加短下划线。 |
| 栏目粗横线 | 同主题色、2 pt 粗，与文字约 2 pt 间距，贯穿正文列宽，左右与条带对齐；不延伸到纸边。 |
| 机构抬头 | 机构、专业/岗位、学位及日期均为 11 pt、加粗、主题深色；基线一致，日期右对齐。 |
| 项目标题 | 10.5 pt、加粗、主题深色；同级一致。 |
| 正文 | 10.5 pt，黑灰；标签加粗，职责句可整体加粗，技术说明通常常规字重。 |
| 联系信息 | 电话、邮箱及 Scholar 主文字 11 pt；GitHub 标签 11 pt、URL 10.5 pt；Scholar 附属统计 10 pt。 |
| 论文题录 | 10.5 pt；主要科研项目题录加粗、斜体，其他题录斜体、序号普通；当前作者名用可读主题色强调，真实共同一作标记保留。 |
| 一级编号 | 原生 `w:numPr`；Wingdings `U+F09F`，符号 10.5 pt。 |
| 二级编号 | 原生 `w:numPr`；Courier New 的 `o`（`U+006F`），符号 7.5 pt。符号字号不改变正文。 |
| 条带外观 | 无粗边框，主题浅底；参考 527.3 × 21.1 pt，文字通常左缩进 24 pt 为图标留空。行内图标方案按真实图形占位，内容较长时增高。 |
| 框内边距 | 通常左右 0、上下 2 pt，顶部对齐；机构文字垂直居中。 |

空白宿主段落的细小字号/行距不是正文规范。复杂公式保留数学字体，编号和图标字形仅在对应字符范围使用必要符号字体，不能把整段正文变成符号字体。

## 行距与对齐

- 正文通常 1.2 倍行距（`w:line=288`、`lineRule=auto`），不是固定 14.4 pt；段前段后从 0 起，块间空白由框位置和高度控制。
- 正文通常两端对齐；姓名、联系方式左对齐。不要用断字或连续空格制造对齐。
- 联系方式约 18 pt 固定行高，图标基线稳定；条带文字垂直居中。
- 一级正文左缩进 7.1 pt、悬挂 7.1 pt；二级默认左缩进 12.75 pt、悬挂 7.1 pt，也有左缩进 17 pt 的较深版本。同级选一种并统一，续行对齐正文起点。
- 教育条带按“学校—专业—学位—日期”，实习条带按“公司/团队—计划或岗位—日期”安排真实字段；无需填满不存在的列。
- 样例教育条制表位：左对齐 126 pt、左对齐 357 pt、右对齐 527.3 pt；实习条：左对齐 126 pt、左对齐 273 pt、右对齐 527.3 pt，相对文字区。组件可按可用宽度重设，长字段不能越过下一列。
- 栏目与至少一段正文同页；正文不靠缩字号、裁切或删事实保持固定页数。框高和间距随实际内容调整，存储高度或 `autoFit` 不等于文字完全可见。

## 页首与图标尺寸

只排入实际提供的信息。默认电话、邮箱及即时通讯在第一行，各自图标在前，用 `｜` 分隔；Scholar 单独一行，可附已确认统计；GitHub 单独一行。用户明确要求全部同一行时，按可用宽度调整标签和头像位置。

用户提供照片时放右上；没有照片默认收回槽位，不复制样例灰框或“照片占位”文字。只有用户要求可填写模板或预留槽位时例外；不搜索下载候选人照片。

| 元素 | 参考尺寸与位置 |
| --- | --- |
| 联系图标 | 视觉高约 11 pt；Scholar 约 11 × 11 pt，GitHub 约 11.23 × 11 pt；图片 run 下移约 1 pt。 |
| 机构图标 | 通常视觉高约 18 pt；横向标识可取约 20 × 17 pt。按有效图形大小和比例调整，不变形，不用 emoji 替代品牌图标。 |
| 姓名与联系框 | 姓名参考坐标 (34, 27.45) pt；三行联系信息顶部示例 58、80、102 pt，左线 34 pt。随实际行数调整。 |
| 照片 | 样例右上槽位约 76.17 × 106.64 pt，仅为起点。 |

图标右侧留文字间隙。页首可选细线与栏目粗横线用途不同；细线避开图标、联系方式和照片，不穿字。品牌资源取得方法见 [图标获取](icons.md)。

## OOXML 格式映射

对每个可见文字 run 显式指定中西文字体与字号，覆盖超链接与条带。下例为正文，其他元素按参数表换算半磅值：

```xml
<w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman" w:eastAsia="KaiTi"/>
<w:sz w:val="21"/>
<w:szCs w:val="21"/>
```

同一 `rPr` 仅保留一个 `w:rFonts`，去掉冲突的 `asciiTheme`、`hAnsiTheme`、`eastAsiaTheme`；`w:szCs` 不能代替 `w:sz`。只设置 `font.name` 常只覆盖西文，只改 Normal 样式不覆盖直接格式。字体读取需解析 run、字符/段落样式及 `basedOn`、`docDefaults`、主题，不能用属性缺失猜测实际字体。

栏目框与正文同宽，左右内边距及段落左右缩进为零。粗横线推荐使用标题段落的原生下边框，使其随标题一起移动：

```xml
<w:pBdr>
  <w:bottom w:val="single" w:sz="16" w:space="2" w:color="2F6FBA"/>
</w:pBdr>
```

`w:sz=16` 对应八分之一磅单位下的 2 pt；示例颜色替换为当前主题。也可用等宽原生线条并与标题联动，不能用 `w:u`、下划线字符或大量带下划线空格模拟。保留足够框高容纳下边框。

常用单位：1 pt = 12700 EMU，1 inch = 914400 EMU；字号及文字基线通常为半磅，段落间距通常为 twip，横线粗细为八分之一磅。依字段换算，不能混用。

样式参数变化时同步脱敏样例、构建模块和由样例重新渲染的预览；单纯流程重构不改变这些视觉资产。验收方法与失败处理统一见 [独立验收](acceptance.md)。
